> **읽기 전 참고** — Windows 11의 프린터 오프라인 문제에 대해 Microsoft, HP, Brother, Canon의 공식 지원 문서를 바탕으로 작성했습니다. 실제 프린터에서 모든 절차를 시험한 것은 아닙니다. 장치 모델·연결 방식·드라이버·Windows 업데이트·조직 정책에 따라 화면과 메뉴가 달라질 수 있습니다.

문서를 인쇄하려는데 Windows 11에서 프린터가 ‘오프라인’으로 나오거나 인쇄 작업만 계속 쌓이나요? 바로 드라이버를 삭제하거나 프린터를 초기화하지 마세요. **프린터 본체 상태 → USB·Wi-Fi 연결 → 선택한 프린터 → 인쇄 대기열 → Windows 문제 해결사 → 스풀러 → 제조사 진단 → 재설치** 순서로 확인하면 원인을 좁히기 쉽습니다. 프린터를 찾지 못하는 문제와 인쇄 도중 멈추는 문제는 처리 방법이 다를 수 있습니다.

## 먼저 읽는 빠른 진단표

| 지금 보이는 증상 | 먼저 확인할 곳 | 불필요한 조치 |
| --- | --- | --- |
| 프린터 화면이 꺼져 있고 인쇄도 안 됨 | 본체 전원, 콘센트, 오류 표시 | 드라이버부터 삭제 |
| Windows에 ‘오프라인’ 표시 | USB·무선·LAN 연결, 선택한 프린터 | 공장 초기화부터 실행 |
| 프린터는 준비 상태인데 문서만 대기 | 인쇄 대기열과 특정 앱 | 공유기 설정 전체 초기화 |
| PDF는 되는데 Word에서만 안 됨 | Word의 프린터·용지 설정 | 프린터 하드웨어 교체 판단 |
| 같은 Wi-Fi의 다른 PC도 인쇄 불가 | 프린터 Wi-Fi, 공유기·네트워크 | 한 PC의 설정만 반복 변경 |
| 다른 PC는 정상, 내 PC만 안 됨 | 내 PC의 프린터 등록·드라이버·스풀러 | 프린터 전체 초기화 |
| 프린터 이름 뒤에 ‘복사 1’ 등이 붙음 | 중복 등록 프린터의 상태 | 모든 항목을 한번에 삭제 |

**중요:** 대기열에서 ‘모두 취소’를 누르면 다른 사람이 기다리는 인쇄 작업까지 취소될 수 있습니다. 공용 프린터라면 먼저 담당자와 작업 여부를 확인하세요.

## 1단계. 프린터 본체부터 확인하기

인쇄가 안 된다고 해서 Windows 설정에 원인이 있는 것은 아닙니다. 프린터에 켜진 표시등이 있는지, LCD 또는 앱에 용지 걸림·덮개 열림·잉크 부족·토너 오류가 표시되는지 확인합니다.

1. 본체 전원이 켜져 있는지 확인합니다. 절전 모드라면 제조사 설명서에 나온 방법으로 깨웁니다.
2. 용지함에 용지가 있고 덮개가 제대로 닫혀 있는지 확인합니다.
3. 화면에 오류 코드가 표시된다면 모델명과 코드를 적고 해당 제조사의 공식 지원 문서를 확인합니다.
4. 인쇄 중인 작업이 없고 장치의 전원 조작이 안전하다면 정상 종료 후 다시 켭니다. Microsoft는 일반적인 문제 해결 과정에서 전원 연결을 분리하고 약 30초 기다렸다 다시 켜는 방법을 안내하지만, 복합기·사무실 공용 장비는 관리자의 절차를 따르세요.

본체에서 지원하는 **구성 페이지 또는 자체 테스트 페이지**가 정상 출력되는데 PC에서만 인쇄되지 않는다면 Windows 또는 연결 쪽을 더 살펴볼 수 있습니다. 자체 테스트가 불가능하다면 본체 오류 해결이 우선입니다. 무리하게 용지나 내부 부품을 잡아당기지 마세요.

## 2단계. USB·Wi-Fi·유선 LAN 연결을 구분하기

### USB로 직접 연결한 경우

- 케이블이 프린터와 PC 양쪽에 끝까지 연결되어 있는지 확인합니다.
- USB 허브를 사용 중이라면 가능할 때 PC 포트에 직접 연결해 비교합니다.
- 다른 USB 포트를 시도할 수 있지만, 포트 변경 후 Windows에서 동일 프린터의 사본을 추가할 수 있으므로 프린터 목록도 함께 확인합니다.
- 케이블이나 포트에 물리적 손상이 있다면 사용을 중단하고 교체 여부를 검토합니다.

### Wi-Fi로 연결한 경우

- 프린터 자체의 Wi-Fi 표시 또는 네트워크 설정에서 연결 여부를 확인합니다.
- PC와 프린터가 같은 로컬 네트워크에서 서로 통신할 수 있는지 확인합니다. 동일한 무선 이름에 접속했더라도 게스트 네트워크나 공유기 분리 정책 때문에 통신이 제한될 수 있습니다.
- 공유기 비밀번호·SSID 변경 또는 이사 이후에 발생했다면 프린터가 예전 네트워크에 연결된 상태인지 살펴봅니다.
- 프린터의 ‘네트워크 구성 페이지’ 출력 기능이 있다면 IP 주소와 연결 상태를 확인합니다. 버튼 조합은 모델마다 다르므로 해당 설명서에서 확인해야 합니다.

### 유선 LAN 연결인 경우

- 프린터와 공유기 또는 사내 네트워크 장비 사이의 LAN 케이블 연결을 확인합니다.
- 프린터의 네트워크 상태 화면에서 IP 주소가 할당되어 있는지 살펴봅니다.
- 회사 네트워크라면 프린터 IP나 방화벽 설정을 임의로 바꾸지 말고 관리자에게 확인합니다.

프린터와 PC의 연결 문제를 점검하는 동안 **공유기 전체 초기화**는 권하지 않습니다. 가정 내 다른 기기의 접속 정보까지 바뀌거나, 회사 네트워크에 영향을 줄 수 있기 때문입니다.

## 3단계. Windows 11에서 올바른 프린터를 선택하기

Windows에서 프린터가 여러 대 표시되면 사용하지 않는 프린터나 ‘Microsoft Print to PDF’를 선택한 채 인쇄를 누르는 경우가 있습니다. 먼저 실제 사용할 장치가 지정돼 있는지 확인합니다.

1. **시작 → 설정 → Bluetooth 및 장치 → 프린터 및 스캐너**로 이동합니다.
2. 목록에서 실제 프린터의 제조사·모델명을 찾습니다.
3. 프린터 상태가 ‘오프라인’인지, ‘유휴’ 또는 ‘준비’에 해당하는 상태인지 확인합니다.
4. 원하는 프린터를 선택한 뒤 **기본값으로 설정**이 필요한지 판단합니다.
5. 기본값 설정 버튼이 보이지 않는다면 Windows가 기본 프린터를 자동 관리하도록 하는 옵션을 먼저 확인합니다.

Windows 11에서 ‘오프라인으로 프린터 사용’이라는 메뉴가 항상 같은 위치에 있는 것은 아닙니다. 이 메뉴가 보이지 않는다고 문제 해결이 불가능한 것은 아닙니다. 일부 Canon 드라이버에서는 Canon IJ Status Monitor의 대기열 메뉴에서 확인하도록 안내하고, Brother는 Windows 버전과 모델에 따라 점검 경로를 따로 구분합니다.

같은 모델 이름이 여러 번 나타난다면 **지금 연결된 프린터와 통신하는 항목**을 찾아야 합니다. Brother는 USB 포트 변경이나 중복 드라이버 설치로 ‘복사 1’ 같은 항목이 만들어질 수 있다고 설명합니다. 현재 작동하는 항목이 확인되기 전에는 목록을 무조건 정리하지 마세요.

## 4단계. 인쇄 대기열에서 멈춘 작업 살펴보기

프린터가 준비 상태인데 문서가 출력되지 않는다면 대기열에 이전 작업이 남아 있는지 확인합니다.

1. **설정 → Bluetooth 및 장치 → 프린터 및 스캐너**로 이동합니다.
2. 해당 프린터를 선택한 뒤 **인쇄 대기열 열기**를 누릅니다.
3. 어떤 문서가 ‘대기 중’, ‘오류’, ‘일시 중지’ 등에 해당하는 상태인지 확인합니다.
4. 잘못 보낸 문서는 선택해서 취소합니다. 일부 화면에서는 더보기(…) 메뉴에 **모두 취소** 기능이 있습니다.
5. 대기열 상태가 바뀌면 가벼운 한 페이지 문서를 다시 인쇄합니다.

**주의:** 모든 작업 취소는 해당 큐의 다른 작업에도 영향을 줄 수 있습니다. 인쇄 중인 작업이 있거나 공유 장치라면 합의 없이 일괄 취소하지 마세요. 작업을 취소했는데도 창에 남아 있다고 해서 즉시 시스템 파일을 직접 삭제할 필요는 없습니다.

같은 문서만 반복 실패한다면 문서 자체의 문제를 확인하세요. 메모장처럼 간단한 앱에서 테스트하고, 그 결과를 원래 문서와 비교하면 프린터 전체 문제인지 특정 앱 문제인지 구분하는 데 도움이 됩니다.

## 5단계. 특정 앱에서만 인쇄가 안 되는지 확인하기

Word, Excel, 브라우저, PDF 뷰어에서 인쇄 결과가 다를 수 있습니다. Microsoft는 특정 앱에서만 오류가 난다면 다른 앱과 다른 파일을 인쇄해 비교할 것을 권장합니다.

- Word에서 실패하면 메모장 또는 다른 앱의 한 줄짜리 문서를 인쇄해 봅니다.
- 같은 앱에서 새 문서를 만든 뒤 인쇄해 기존 파일만의 문제인지 확인합니다.
- 앱의 **파일 → 인쇄**에서 프린터 이름, 용지 크기(A4 등), 방향, 페이지 범위를 확인합니다.
- 인쇄 대상이 실제 프린터가 아닌 PDF 저장 또는 파일 인쇄로 설정돼 있지 않은지 확인합니다.

Windows 11에서는 프린터 설정의 **프린터 속성 → 일반 → 테스트 페이지 인쇄**로 시스템 수준의 출력 여부를 확인할 수 있습니다. 테스트 페이지도 실패한다면 특정 문서의 서식보다 연결·드라이버·인쇄 서비스에 우선순위를 두세요.

복합기의 스캔 기능이 정상이라고 해서 인쇄 기능도 정상임을 보장하지는 않습니다. 스캔과 인쇄는 서로 다른 드라이버 또는 서비스 경로를 사용할 수 있습니다.

## 6단계. Windows의 프린터 문제 해결사 사용하기

Microsoft는 Windows 11에서 **도움말 보기(Get Help)** 앱의 자동 프린터 문제 해결사를 안내합니다. Windows의 최신 지원 문서에서도 연결·설정·대기열 문제를 진단하는 방법으로 제시합니다.

1. Windows에서 ‘도움말 보기’를 검색해 앱을 엽니다.
2. 프린터 또는 인쇄 문제 관련 문제 해결 항목을 찾습니다.
3. 표시되는 권장 단계를 읽고, 진단을 실행합니다.
4. 도구가 설정 변경을 제안한다면 어떤 변경인지 먼저 확인합니다.
5. 완료 후 프린터의 상태를 다시 확인하고 테스트 페이지를 인쇄합니다.

문제 해결사의 화면 구성과 자동 실행 항목은 Windows 빌드 및 장치 정책에 따라 달라집니다. 조직이 관리하는 PC에서 권한을 요구하거나 도구가 실행되지 않는다면 관리자에게 문의해야 합니다. ‘진단 완료’ 메시지만으로 해결됐다고 판단하지 말고 실제 출력 결과로 확인하세요.

## 7단계. 인쇄 스풀러 서비스 재시작하기

인쇄 스풀러(Print Spooler)는 Windows가 인쇄 작업을 관리하는 서비스입니다. 작업이 취소되지 않거나 새 문서도 계속 멈춘다면 이 서비스를 재시작하는 방법을 검토합니다.

1. **Windows 키 + R**을 누릅니다.
2. 실행 창에 <code>services.msc</code>를 입력하고 Enter를 누릅니다.
3. 목록에서 **인쇄 스풀러(Print Spooler)**를 찾습니다.
4. 서비스를 마우스 오른쪽 버튼으로 클릭하고 **다시 시작**을 선택합니다.
5. 필요하면 PC를 다시 시작한 후 새 테스트 문서를 인쇄합니다.

서비스 관리에는 관리자 권한이 필요할 수 있습니다. 공용 프린터 서버나 업무용 PC에서는 다른 사용자의 인쇄가 영향을 받을 수 있으므로 승인받기 전 실행하지 마세요.

Microsoft는 이전 단계로 해결되지 않을 때 스풀러를 중지하고 대기 파일을 지우는 방법도 안내하지만, 이는 **진행 중인 작업을 없애는 조치**입니다. 이 문서에서는 일반 사용자가 시스템 폴더 안의 파일을 직접 지우는 것을 기본 해결책으로 권하지 않습니다. 서비스 재시작으로 문제가 해결되지 않고 업무 영향이 우려된다면 담당자 또는 제조사 지원을 이용하세요.

## 8단계. HP·Brother·Canon에서 제조사별 도구 점검하기

장치 제조사와 모델에 따라 Windows에서 제공하는 진단만으로 해결되지 않을 수 있습니다. 제조사 앱이나 상태 모니터가 설치된 경우 그 도구에서 오류 표시를 다시 확인합니다.

### HP 프린터

HP는 프린터 지원 사이트에서 오프라인 및 대기열 문제를 위한 진단 수단을 제공합니다. 최근 HP 지원 안내에 따르면 **HP 앱이 많은 프린터에서 HP Smart를 대체**하고 있지만 운영체제와 기기별로 이용할 수 있는 앱이 다릅니다. 따라서 과거 안내문에 ‘HP Smart’라고 적혀 있다는 이유만으로 무조건 이전 앱을 설치하지 말고, HP 공식 지원 페이지에서 모델을 선택해 현재 권장되는 앱을 확인하세요. HP 앱으로 설치한 프린터에 추가 드라이버를 중복 설치하는 것은 권장하지 않습니다.

### Brother 프린터

Brother 공식 도움말은 전원·오류 표시, USB·유선·무선 연결, 대기열, 중복 드라이버를 확인하도록 안내합니다. 일부 모델에는 프린터의 무선 모듈을 다시 시작하는 버튼 절차가 있지만 **기종별 버튼 조합을 범용 지침으로 따라 하면 안 됩니다.** 모델명에 맞는 온라인 설명서를 확인하세요. Windows 11에서는 선택한 프린터의 상태와 대기열을 확인하는 단계를 우선합니다.

### Canon 프린터

Canon의 일부 잉크젯 모델은 **Canon IJ Status Monitor**에서 인쇄 대기열 및 ‘오프라인으로 프린터 사용’ 설정을 확인하도록 안내합니다. 하지만 이 경로는 Canon 전체 제품군의 공통 메뉴가 아닙니다. 해당 모델에 MP Drivers·상태 모니터가 제공되는지 공식 설명서를 확인하세요. 일부 기종에서는 Windows 보호 인쇄 모드가 제조사 드라이버 사용에 영향을 줄 수 있다고 안내합니다. 이 설정은 보안 관련 기능이므로 조직 정책에 반해 임의로 끄지 마세요.

### Epson·Samsung 등 다른 제조사

지원 사이트에서 제품의 **정확한 모델명과 운영체제 버전**을 입력해 권장 진단·드라이버·네트워크 설정 절차를 확인합니다. Samsung 브랜드 프린터도 제품과 지원 경로가 다를 수 있으므로 실제 라벨의 모델명을 기준으로 찾으세요. 위의 HP·Brother·Canon 메뉴를 다른 제조사 제품에 그대로 적용하지 마세요.

## 9단계. 모든 기본 점검 후에만 재설치 검토하기

연결이 정상인데 Windows에서 프린터가 계속 인식되지 않거나, 정확한 모델의 드라이버 문제가 확인된다면 재설치를 검토할 수 있습니다.

1. 프린터의 정확한 모델명, 연결 방식, 현재 사용 중인 프린터 이름과 인쇄 설정을 기록합니다.
2. 회사·학교 장치라면 관리 권한이 있는지 확인하고 담당자에게 문의합니다.
3. Microsoft의 **설정 → Bluetooth 및 장치 → 프린터 및 스캐너**에서 해당 장치를 선택합니다.
4. 그 모델의 공식 Windows 설치 절차와 드라이버를 확인합니다.
5. 필요성이 확인됐을 때만 프린터를 제거하고, **장치 추가**를 사용해 다시 설치합니다.
6. 새로 등록한 프린터에서 테스트 페이지를 인쇄하고, 일반 문서도 확인합니다.

제조사 드라이버를 찾아 설치할 때는 정확한 모델·운영체제·아키텍처에 맞는 파일을 사용합니다. 출처 불명의 ‘자동 드라이버 업데이트’ 프로그램은 사용하지 마세요. Microsoft는 일부 ARM 기반 Windows PC에서 제조사 설치 관리자가 설치에 실패할 수 있으므로 Windows의 기본 프린터 추가 경로를 권장합니다.

프린터의 공장 초기화, 공유기 초기화, IP 설정 임의 변경은 위 순서보다 더 큰 영향을 줄 수 있으므로 이 안내의 기본 단계에 포함하지 않습니다.

## 자주 묻는 질문

### 프린터가 켜져 있는데 왜 오프라인이라고 나오나요?

Windows가 해당 프린터와 통신하지 못하거나, 다른 드라이버 사본·기본 프린터·대기열을 보고 있을 수 있습니다. 본체 전원과 네트워크 연결을 확인하고, Windows의 프린터 목록에서 실제 사용 중인 장치를 선택해 보세요. 전원이 켜져 있다는 사실만으로 PC와 정상 통신하고 있다고 볼 수는 없습니다.

### Wi-Fi 프린터인데 인터넷이 연결돼 있어야 하나요?

모든 로컬 인쇄가 외부 인터넷 접속을 요구하는 것은 아닙니다. 다만 프린터와 PC가 같은 네트워크에서 통신 가능해야 하며, 제조사의 클라우드 인쇄 기능이나 특정 앱은 인터넷을 요구할 수 있습니다. 로컬 인쇄와 클라우드 인쇄를 구분해 확인하세요.

### ‘오프라인으로 프린터 사용’을 체크 해제하면 끝인가요?

체크된 오프라인 모드를 해제하는 것이 도움이 될 수 있지만, Windows 11·제조사 드라이버별로 메뉴 위치와 제공 여부가 다릅니다. 실제 연결이 끊겼다면 메뉴만 변경해도 다시 오프라인으로 표시될 수 있습니다. Brother의 Windows 11 안내와 Canon의 모델별 상태 모니터 안내는 절차가 서로 다릅니다.

### 프린터 드라이버를 꼭 새로 설치해야 하나요?

그렇지 않습니다. Windows는 다수 프린터를 기본적으로 지원하며, 기존 드라이버가 정상이라면 재설치할 이유가 없습니다. 연결·대기열·스풀러·공식 진단을 먼저 확인하세요. 재설치는 모델에 맞는 설치 파일과 복구 방법을 확인한 뒤 진행합니다.

### 인쇄 대기열을 비우면 원본 파일도 삭제되나요?

대기열 취소는 인쇄 요청을 취소하는 작업으로, 일반적으로 원본 문서 파일을 삭제하는 조치는 아닙니다. 하지만 해당 큐의 진행 중인 인쇄는 중단될 수 있으므로 공유 프린터에서는 주의하세요.

### Windows 10도 같은 방법인가요?

연결과 스풀러를 확인하는 기본 원리는 비슷하지만 설정 화면과 메뉴가 다릅니다. 이 원고는 **Windows 11을 기준**으로 작성했습니다. Microsoft는 Windows 10 일반 지원이 2025년 10월 14일 종료됐다고 안내하므로, Windows 10 사용자는 지원 상태와 모델별 문서를 별도로 확인하세요.

## 해결 여부를 확인하는 최종 체크리스트

- [ ] 프린터 본체의 오류 표시가 없고, 전원이 켜져 있습니다.
- [ ] USB 또는 네트워크 연결이 실제로 확인됐습니다.
- [ ] Windows에서 올바른 프린터와 모델을 선택했습니다.
- [ ] 인쇄 대기열에 오래된 오류 작업이 남아 있는지 확인했습니다.
- [ ] Windows 테스트 페이지가 출력됩니다.
- [ ] 메모장 등의 간단한 문서를 출력했습니다.
- [ ] 원래 실패했던 파일도 다시 인쇄했습니다.
- [ ] 공유 장비라면 다른 사용자의 인쇄에 문제가 없는지 확인했습니다.

**핵심 정리:** 프린터가 오프라인으로 표시될 때 가장 먼저 할 일은 삭제나 초기화가 아니라 **어디까지 통신이 되는지 확인하는 것**입니다. 본체 상태, 연결, 프린터 선택, 대기열을 차례로 확인하고 그래도 해결되지 않을 때 공식 진단과 재설치를 검토하세요. 해결 여부는 상태 표시만이 아니라 **테스트 페이지와 실제 문서의 출력**으로 판단해야 합니다.
